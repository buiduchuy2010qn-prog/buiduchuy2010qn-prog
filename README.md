## 🚀 Mình đang xây dựng

- **Windows Desktop:** tiện ích hệ thống gốc nhẹ, mượt (UpdateLayeredWindow, WASAPI, DPI-aware).
- **Android & Hệ điều hành:** ứng dụng hiệu năng cao, trình khởi chạy và giải pháp DSU ROM an toàn.
- **Minecraft Ecosystem:** công cụ quản trị server và trình khởi chạy tự động tối ưu FPS / Mod.
- **Web Interactive:** những trải nghiệm tương tác nhanh, trực quan và giải trí.
